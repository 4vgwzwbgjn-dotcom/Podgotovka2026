# Подготовка к тестированию 2026 — iOS

Нативное iOS-приложение на SwiftUI для подготовки по двум независимым темам:

- **Технические вопросы 2026** — 225 вопросов
- **Ответственные за БПР 2026** — 199 вопросов
- всего **424 вопроса**

## Функции

- тёмный интерфейс;
- главный экран с двумя темами и прогрессом;
- выбор срока обучения от 1 до 90 дней;
- умный режим: все текущие ошибки + до 10 новых вопросов;
- ошибки автоматически переходят в следующее повторение;
- после неправильного ответа показываются правильный ответ и объяснение из базы;
- статистика;
- сброс отдельной темы;
- полный сброс обучения;
- экзамен на 20 случайных вопросов;
- условие сдачи экзамена: не более 2 ошибок;
- база вопросов сохранена в `PodgotovkaTestiOS/Resources/questions.json`.

## Важно про IPA

`.ipa` для установки на физический iPhone должен быть **подписан Apple**. Поэтому один только ZIP проекта не является готовым IPA. Проект уже подготовлен для Xcode и GitHub Actions; для персональной установки проще всего открыть проект на Mac в Xcode, выбрать свой Apple Account в Signing & Capabilities и запустить на iPhone.

Для распространения готового `.ipa` через GitHub Actions нужны Apple signing credentials (сертификат/ключ и provisioning profile) либо App Store Connect/TestFlight workflow. Без подписи iPhone не установит IPA.

### Вариант A — iPhone + Xcode без платной подписки

1. Распаковать проект на Mac.
2. Открыть `PodgotovkaTestiOS.xcodeproj`.
3. В Xcode открыть target **PodgotovkaTestiOS → Signing & Capabilities**.
4. В поле **Team** выбрать свой Apple Account / Personal Team.
5. Подключить iPhone и включить Developer Mode, если Xcode попросит.
6. Выбрать iPhone как Run Destination и нажать Run.

У Personal Team Apple ограничивает срок provisioning: приложение нужно периодически переподписывать/переустанавливать; Apple указывает срок 7 дней для таких профилей.

### Вариант B — настоящий IPA для передачи на зарегистрированные iPhone

Нужен Apple Developer Program и зарегистрированные устройства для Ad Hoc, либо TestFlight/App Store distribution. После этого Xcode экспортирует подписанный `.ipa`.

## GitHub Actions

В репозитории можно использовать macOS runner и `xcodebuild archive` + `xcodebuild -exportArchive`. Для подписанного IPA необходимо настроить секреты Apple signing. Без них workflow может собрать архив, но не сможет выпустить устанавливаемый на iPhone IPA.
